# فاتورتي — Fawatery

تطبيق Android للفواتير والعملاء والكتالوج، يعمل دون اتصال أو تسجيل دخول.

## الوظائف
- حفظ محلي دائم بمعاملات SQLite، مع حماية البيانات عند فشل الكتابة أو تعذّر قراءتها.
- ترقيم فواتير لا يعتمد على عدد السجلات ولا يعيد استخدام الرقم بعد الحذف.
- حسابات SAR بالهللة، وتحقق من الكمية والسعر والخصم والتواريخ.
- أرصدة عملاء وإجماليات تتحدث من الفواتير، مع استبعاد المسودات من المبيعات والضريبة.
- تصدير PDF عربي متعدد الصفحات وCSV لجميع فواتير الفترة.
- QR فعلي لبيانات الفاتورة. لا يدّعي التطبيق اعتمادًا ضريبيًا ولا ينفذ ربط المرحلة الثانية للهيئة.
- اقتراحات تذكير بتاريخ اليوم وإعدادات محفوظة؛ إرسال واتساب وSMS يتم بإجراء منك.

الرقم الضريبي للمنشأة والعميل اختياري. يمكنك إصدار وتصدير الفاتورة بدونه؛ QR الضريبي يظهر للفواتير التي تتضمن رقم منشأة صحيحًا.

لتغيير الشعار: افتح «المنشأة»، اختر «اختيار شعار من الصور»، ثم اضغط «حفظ كافة التعديلات». يدعم صور PNG وJPEG وغيرها من الصور التي يقرأها الجهاز حتى 10 ميجابايت، ويحفظ نسخة محلية مع ضبط الاتجاه والأبعاد. يظهر الشعار في معاينة الفاتورة وPDF، وتحتفظ الفواتير الصادرة بشعارها السابق. لا توجد فواتير أو عملاء تجريبيون داخل سجلك الفعلي.

## التحقق والبناء
يتطلب JDK 17 وAndroid SDK 36.1 وGradle wrapper المرفق. GitHub Actions يعدّ مفتاح Debug مؤقتًا ويشغّل:

```sh
./gradlew assembleDebug
./gradlew :app:testDebugUnitTest
# مع محاكي أو جهاز Android متصل:
./gradlew :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.example.InvoicePdfTest
```

Artifact: fawraty-debug-apk. الاختبارات تنتج أيضًا PDF وصورًا ببيانات اصطناعية ضمن invoice-pdf-validation.
راجع [سياسة الحسابات والتحقق](docs/INVOICE-VALIDATION.md). نسخة Debug ليست إصدار متجر.


## الشعار وعروض الأسعار وPDF
- من شاشة إنشاء الفاتورة يمكنك اختيار شعار لهذا المستند، أو الرجوع لشعار المنشأة. لا يغير ذلك شعار المنشأة العام.
- افتح «العروض» ثم «عرض سعر جديد». أدخل العميل والبنود والرقم الضريبي الاختياري ومدة الصلاحية، واحفظ العرض ثم شاركه PDF.
- يمكن تعديل العرض قبل التحويل. «تحويل إلى فاتورة» ينشئ فاتورة واحدة فقط برقم مستقل وتاريخ اليوم واستحقاق افتراضي بعد 14 يومًا، مع الحفاظ على البنود والأسعار وشعار العرض. العرض المنتهي يحتاج تحديث الصلاحية أولًا.
- عروض الأسعار لا تدخل المبيعات أو الضريبة المستحقة أو مديونية العملاء قبل تحويلها. حذف عرض محوّل لا يحذف الفاتورة الناتجة.
- PDF يعرض البنود في جدول عربي مع التفاف كل خلية وتكرار رؤوس الأعمدة في الصفحات التالية، وملخص إجمالي واضح. عرض السعر له عنوان ومدة صلاحية ولا يحمل QR فاتورة ضريبية.
- يحتفظ محرر المستند بالبنود والأسعار والمدخلات غير الصالحة عند إعادة إنشاء الشاشة، ويمنع حفظ القيم القديمة بدل مدخل غير صالح.
